# 使用说明

通过 [网页版](https://doublequiet-on.github.io/ournotes-team-planner-web/) 打开，建议使用电脑的近期 Chrome 或 Edge。第一次需要下载 Python 与求解组件，可能自动刷新一次。

1. 导入本地版导出的个人卡库 JSON，或在「我的卡库」分别添加成员卡与 Snap。新卡默认不参与搜索。
2. 填写卡牌实际等级、特训或突破、觉醒和技能等级。空白表示未知，不能用最大养成代替。
3. 在「角色与道具」填写对应角色等级、总角色等级、T.G.W 等级和相关乐队的全部道具。
4. 勾选参与搜索的候选卡，至少包含 5 位不同角色的成员卡和 5 张 Snap。
5. 在「收益规划」填写 Boost 总预算、已有 CP、每场消耗，分别选择普通与挑战歌曲、难度及 AP/跳过方式。
6. 查看「本次所需养成」，补齐后点击计算。计算期间可以取消；完整搜索与最优验证结束后才展示方案。

每种收益目标分别显示普通队、挑战队、资源消耗与剩余，以及两种演出各自的不同歌曲前三名。要得到完整前三名，普通与挑战都应各选择至少 3 首不同歌曲。每首排名歌曲绑定自己的配队，不能把第一首的队伍直接当作其他歌的队伍。

卡库自动保存在当前浏览器。使用「导出卡库」保留可在其他浏览器导入的 JSON；「导出计算结果」保存本次实际输入和完整结果。修改输入后，旧结果立即失效，需要重新计算。

取消或刷新中断后，下次可以「恢复上次输入并继续」。已保存的完整谱面、成员队伍进度或最优验证步骤可复用；未完成步骤重新开始。保存失败时页面会提示，关闭前请导出卡库和结果。

同一网址的另一标签页正在计算时，本页不能同时开始计算。另一标签页修改卡库后，旧页会锁定编辑并提示刷新；旧页仍可导出自己的输入。刷新后读取最新保存的卡库。

计算速度和可用内存由访问者设备决定。保持页面打开；手机切到后台可能被系统中断。清理网站数据、换浏览器、换设备或换网站路径会影响本地记录，操作前先导出卡库。手机实机和 QQ 内置浏览器的计算能力尚未完成验收。

当前模型只覆盖固定活动 ID 1、普通单人自由演出与撃奏关闭。AP 评级按模型条件估算，不代表每次实机必然达到；自然恢复、养成费用和跳过券另计。完整边界见 [数据说明](DATA.md)。
