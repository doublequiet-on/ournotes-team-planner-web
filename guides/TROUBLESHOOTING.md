# 故障排查

| 现象 | 处理 |
| --- | --- |
| 第一次停留在准备运行 | 等待运行组件下载；使用电脑近期 Chrome/Edge，通过 HTTPS 或 localhost 打开 |
| 提示计算环境未启用 | 允许网站保存数据，用外部浏览器重新打开，刷新重试 |
| 卡图或 Worker 返回 404 | 检查完整静态目录是否上传；不要只上传 index.html，确认 Pages 使用 main/docs |
| 提示旧标签页 | 先导出该页需要保留的输入，再刷新读取最新卡库 |
| 提示另一标签页正在计算 | 完成或取消那页的计算；关闭已中断的旧页后重试 |
| 提示续算缓存损坏 | 卡库独立保留；重新计算会建立新的有效缓存 |
| 提示保存失败 | 当前输入仍可导出；关闭前备份，检查网站存储权限或空间 |
| 提示计算进程中断 | 导出卡库后刷新；缩小本次实际需要比较的候选范围或改用更有内存的电脑 |
| 长时间显示最优验证 | 仍在搜索；没有完成之前不能把可行队伍当作最优，可以取消后继续 |
| 找不到上次卡库 | 核对网址、浏览器与用户配置；无痕窗口、清理网站数据和不同设备不共享记录 |
| 修改公式后结果未变 | 构建读取固定 ZIP；修改 work/model 不会改变网页，需要按数据说明更新基准 |

不要为恢复计算而直接清理整个网站数据：那会同时删除个人卡库。先导出卡库与需要保留的结果。手机窄屏布局已检查，但手机实机、后台切换与 QQ 内置浏览器未完成性能验收。

反馈问题时提供网页版本、模型版本、浏览器、复现步骤和错误文字。需要分享卡库时，先确认其中是愿意公开的输入；开发者可以使用合成测试值重现，不必索取原玩家截图或账号资料。
